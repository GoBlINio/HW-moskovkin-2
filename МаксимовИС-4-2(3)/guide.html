1. Структура HTML-документа

Каждый стандартный HTML-документ состоит из базового каркаса:

  • <!DOCTYPE html> — объявление типа документа.
  • <html> — корневой элемент страницы.
  • <head> — хранит техническую информацию (заголовок, кодировку, CSS-стили).
  • <body> — содержит весь видимый контент страницы.

2. Форматирование текста

Теги для работы с заголовками, абзацами и выделением текста:

  • <h1> ... <h6> — заголовки разных уровней.
  • <p> — параграф (абзац) текста.
  • <b> или <strong> — жирный текст.
  • <i> или <em> — курсивный текст.
  • <br> — принудительный перенос строки.
  • <hr> — горизонтальная линия-разделитель.

3. Списки (маркированные и нумерованные)

Списки используются для группировки связанных элементов:

  • <ul> — маркированный (ненумерованный) список.
  • <ol> — нумерованный список.
  • <li> — отдельный пункт списка (используется внутри <ul> или <ol>).

↑ Вернуться к оглавлению

4. Таблицы

Таблицы служат для представления структурированных данных:

  • <table> — контейнер таблицы.
  • <tr> — строка таблицы.
  • <td> — ячейка с данными.
  • <th> — заголовочная ячейка (текст внутри жирный и по центру).

Основные атрибуты ячеек: colspan (объединение колонок) и rowspan (объединение строк).

5. Ссылки и изображения

Элементы для связи страниц и добавления медиафайлов:

  • <a href="URL"> — гиперссылка. Для перехода на внешние сайты или внутри документа через метки #id.
  • <img src="путь" alt="описание"> — вставка изображения.
